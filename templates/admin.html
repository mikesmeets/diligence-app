Financial Modeling Prep API Key

FMP restricts coverage by ticker as well as by endpoint, so test the ticker you actually care about — a pass on AAPL says nothing about the rest.

Write-only, like the Anthropic key — never sent back to this page once saved. Setting FMP_API_KEY as an environment variable on Railway takes precedence and keeps the key out of the database entirely.

Alpha Vantage API Key

Used when FMP can't answer. Carries forward EPS and revenue with high/low dispersion and 30/90-day revision trends — but no forward EBITDA or EBIT, so those rows stay blank. The free tier allows 25 requests per day, so responses are cached for six hours. ALPHAVANTAGE_API_KEY as an environment variable takes precedence, same as the others.

Diagnose a Ticker

Asks FMP, Alpha Vantage and Yahoo the same question and shows what each one actually said. Use it when the Consensus block falls back and the reason isn't obvious. Costs one Alpha Vantage call.

Emailed Ideas — Mailbox

Use a mailbox dedicated to this. IMAP grants read access to everything in the account, so pointing it at your personal inbox hands the app all of your mail. Forward ideas into the dedicated mailbox instead.

Gmail needs an app password with 2-step verification on — your normal password will be refused. The password is write-only here; setting INBOX_IMAP_PASSWORD on Railway takes precedence and keeps it out of the database.

Emailed Ideas — Webhook

For a mail service (Mailgun, SendGrid, Postmark, CloudMailin) posting straight to the app. The URL below carries the shared secret — anyone holding it can file ideas into your tracker, so treat it as a password and rotate it if it leaks.
